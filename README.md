# xiaozhushou · 提醒喝水小助手

基于 Arduino Nano 的智能杯座。红外传感器检测杯子，OLED 显示时间、DS3231 芯片温度和提醒进度，有源蜂鸣器提醒拿起水杯。

## 硬件与接线

| 器件 | Nano 引脚 / 配置 |
| --- | --- |
| 红外检测器 | D4；沿用原电路：HIGH 表示杯子在位，LOW 表示移开 |
| 有源蜂鸣器 | D13；HIGH 发声，LOW 静音 |
| SSD1306 OLED | 128×64、I2C；SDA=A4、SCL=A5；无独立复位线 |
| DS3231 RTC | 与 OLED 共用 I2C 总线 |

开发板配置来自原仓库：`arduino:avr:nano:cpu=atmega328`。蜂鸣器驱动方式及传感器电平须与上述约定一致。

## 运行规则

- 默认间隔 **60 分钟**，依据 `millis()` 的实际经过时间计时，屏幕每秒刷新；拿杯和提醒不使用 `delay()` 或等待传感器的死循环。
- 杯子在开机时已经放好则立即开始计时；开机没有杯子时，第一次放入只启动计时，不计为喝水。
- 传感器状态稳定 **50 毫秒**才确认拿起/放回。一次完整的“拿起 → 放回”结束时重置计时，并更新间隔的指数加权平均，近期权重 **0.6**。拿杯期间仍显示时间，不冻结程序；统计间隔包含拿杯期间的时间。系统只能识别拿放事件，不能判断是否实际喝水。
- 到期时有源蜂鸣器按 **300 毫秒响 / 300 毫秒停**提醒，最多 **18 秒**。采样到杯子移开立即静音；次数统计仍经过消抖。超时后保持静音，显示“Lift cup to reset”，完整拿放后再开始一轮，不武断判定传感器故障。
- 按 RTC 的本地小时，在 **23:00–次日10:00** 静音，与原代码实际静音时段一致。夜间到期后屏幕显示 **Drink (silent)**（喝水提醒，静音），未到期显示 Quiet hours；拿起后显示 Cup removed，只有放回才更新喝水统计并重置提醒。即使白天蜂鸣已超时，夜间仍显示喝水提示。夜间到期不消耗蜂鸣时长、不进入错误锁定；白天到来后，尚未耗尽蜂鸣时长的到期提醒恢复发声。时段切换检测精度受每秒 RTC 刷新影响。
- 首次连接不到 RTC 时显示错误并保持静音；检查接线后重新启动。RTC 检测到掉电时用固件编译时间初始化，正式使用前应确认该时间与当地时间相符。
- 控制器使用无符号时间差处理 `millis()` 回绕；极长的未重置周期饱和保持“已到期”，不会重新显示满进度。

`Reminder.h` 管理计时、去抖和提醒逻辑，`xiaozhushou.ino` 负责引脚、RTC 和显示。修改提醒间隔、静音时段、去抖时间可调整头文件常量；引脚在 sketch 顶部配置。

## 编译与测试

Arduino IDE 中选择 Arduino Nano，并从库管理器安装 **U8g2**、**RTClib** 及其依赖。也可以用 Arduino CLI：

```sh
arduino-cli core update-index
arduino-cli core install arduino:avr
arduino-cli lib install U8g2 RTClib
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328 .
```

有些旧 Nano 使用旧 bootloader，需要选择 `cpu=atmega328old`；以实际硬件为准。以上命令只编译，不烧录。

纯控制逻辑测试不依赖 Arduino 或实际设备：

```sh
sh tests/run.sh
```

覆盖真实的60分钟边界、蜂鸣节拍及18秒上限、杯子拿放、输入抖动、开机无杯、跨夜恢复、32位时间回绕及长时间未重置。

## 本次修正

原程序每60次循环减一分钟，但循环末尾是 `delay(20)`，导致时间被大幅压缩。现在按实际经过时间推进；等待杯子和蜂鸣逻辑也不再阻塞整个主循环。到期进度正确归零，拿杯时间纳入间隔统计。

OLED 构造函数第二个参数是 reset，而不是 SCL；现改为板载硬件 I2C 默认引脚与无复位脚配置。采用 `_1_` 单页缓冲（128字节）代替 `_F_` 全屏缓冲（1024字节），为 Nano 的2KB SRAM留出余量；文字常量放入 Flash。显示传输本身仍是同步 I2C 操作。

接口依据：[U8g2 构造参数及缓冲模式](https://github.com/olikraus/u8g2/wiki/u8g2setupcpp)。

编译和逻辑模拟不能代替硬件验证。烧录后请确认传感器极性、实际 OLED 型号、蜂鸣器响停、RTC 时间，以及实物拿放时的表现。
